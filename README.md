A browser-based Aura of Intelligence ecosystem portfolio presented as a 22-slide, single-file slideshow. It introduces the core platform and a broad set of connected health, governance, creative, finance, place and space concepts.

## Public page

[Open the live slideshow](https://auraofintelligence.github.io/20-components/).

## Explore the portfolio

Use **Previous** and **Next**, the overview grid, arrow keys or touch gestures to move through the slides. Several slides contain small interactive controls for exploring assumptions. The final controls can print the presentation or save it as a PDF through the browser.

The closing contact form is only interface scaffolding: pressing **Submit** displays a confirmation in that browser and does not send the entered details anywhere.

## Open it locally

Open `index.html` in a modern browser. The page is self-contained apart from externally hosted fonts. There is no build step, account, database or backend.

## Status and boundaries

This repository is an ecosystem concept presentation, not proof that every component exists as a working product, registered entity, funded program or approved partnership. Interactive figures and portfolio settings are explanatory scenarios. They should not be treated as current financial, legal, medical, cultural or investment advice.
